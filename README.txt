HASAN COC EMOTIONAL YOUTUBE PACKAGE

ফাইলগুলো:
- index.html: ওয়েবসাইট/কনটেন্ট ভিউয়ার
- style.css: ডিজাইন
- script.js: দিন নির্বাচন ও কপি ফিচার
- content.json: ৩০ দিনের ভয়েস স্ক্রিপ্ট, টাইটেল, ডেসক্রিপশন, ট্যাগ, হ্যাশট্যাগ

GitHub Pages:
1. সব ফাইল একই রিপোজিটরির Root-এ আপলোড করুন।
2. Settings > Pages > Deploy from a branch নির্বাচন করুন।
3. Branch হিসেবে main এবং folder হিসেবে /root নির্বাচন করুন।
4. Save চাপুন।
5. কিছুক্ষণ পর Visit site চাপুন।

গুরুত্বপূর্ণ:
- content.json ফাইলটি index.html-এর পাশেই থাকতে হবে।
- ফাইলের নাম পরিবর্তন করলে script.js-এর fetch path-ও পরিবর্তন করতে হবে।
